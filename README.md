### supported formats

| category | formats | capabilities |
| :--- | :--- | :--- |
| **audio & cds** | `.mp3`, `.flac`, `.m4a`, `.ogg`, `.opus`, `.wav`, `.aiff`, `.wma`, `.cda` | edit tags, cover art, lyrics, full strip, `.cue` export |
| **images** | `.jpg`, `.jpeg`, `.png`, `.webp`, `.gif`, `.svg` | exif / iptc / xmp / gps edit, spoof, lossless full strip, json-ld |
| **documents** | `.pdf`, `.docx`, `.xlsx`, `.pptx`, `.odt`, `.ods`, `.odp`, `.epub`, `.html` | inspect, edit, strip author & editor metadata |
| **apps & binaries** | `.apk`, `.apkm`, `.apks`, `.xapk`, `.aab`, `.ipa`, `.tipa`, `.deb`, `.exe`, `.dll`, `.msix`, `.jar`, `.elf`, `.dylib`, `.wasm` | manifest / plist / version info inspect, edit, timestamp & build-meta strip |
| **drives & archives** | folders, usb drives, audio cds, `.zip` | recursive scan, batch tools, direct usb write-back, `.zip` export |

### shortcuts

`d` cd/usb · `z` .zip · `↑↓` select · `a` select all · `r` spoof · `x` strip · `b` batch · `⌘z` undo · `⌘k` commands · `?` reference · `esc` home
